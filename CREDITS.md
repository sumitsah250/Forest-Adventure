# Credits

## Code

All game code, procedural geometry (trees, undergrowth, rocks, logs, buildings, vehicles, the characters and all
eight firearms) and procedural textures (needle sprays, decals, signs, map, fabrics, wood grain, targets) were
written for this project. Weapon names, manufacturers and the people in the story are fictional.

## Libraries

- three.js (MIT License): https://threejs.org
- Rapier physics, `@dimforge/rapier3d-compat` (Apache-2.0): https://rapier.rs
- Vite (MIT), TypeScript (Apache-2.0), playwright-core (Apache-2.0; tests only)
